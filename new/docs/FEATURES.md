# Audio Player Features

## 🎵 Core Audio Features

### Playback Controls
- **Play/Pause** - Toggle audio playback with spacebar
- **Previous/Next** - Navigate through playlist
- **Shuffle Mode** - Random song order playback
- **Repeat Modes** - No repeat, repeat all, repeat one
- **Volume Control** - Adjustable volume with mute option
- **Seeking** - Click progress bar to jump to position

### Audio Support
- **Multiple Formats** - MP3, WAV, OGG, M4A, FLAC, AAC
- **High Quality** - Supports lossless audio formats
- **Metadata** - Automatic duration and file size detection
- **Error Handling** - Graceful handling of corrupted files

## 📚 Library Management

### Organization
- **Folder Structure** - Organize music by genre/artist/album
- **Auto-Detection** - Automatically scans music directory
- **Real-time Updates** - Refresh library without restart
- **Nested Folders** - Support for subdirectories

### Search & Filter
- **Global Search** - Search across all songs and folders
- **Folder Filtering** - View songs from specific folders
- **Live Results** - Real-time search as you type
- **Case Insensitive** - Flexible search matching

## 🎶 Playlist Management

### Dynamic Playlists
- **Add Songs** - Individual song addition to playlist
- **Bulk Add** - Add all displayed songs at once
- **Remove Songs** - Remove individual songs from playlist
- **Reorder** - Click to play any song in playlist

### Playlist Features
- **Current Playing** - Visual indicator of active song
- **Queue Management** - See what's coming next
- **Persistent State** - Playlist maintained during session
- **Context Actions** - Right-click for quick options

## 🎨 User Interface

### Modern Design
- **Responsive Layout** - Works on desktop and mobile
- **Gradient Backgrounds** - Beautiful visual design
- **Smooth Animations** - Hover effects and transitions
- **Icon Integration** - Font Awesome icons throughout

### User Experience
- **Keyboard Shortcuts** - Full keyboard navigation
- **Context Menus** - Right-click for quick actions
- **Loading States** - Visual feedback during operations
- **Error Messages** - Clear error communication

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Space | Play/Pause |
| ← | Previous Song |
| → | Next Song |
| ↑ | Volume Up |
| ↓ | Volume Down |
| Enter | Search |
